# PHP & MySQL User Registration System

A beginner-friendly user registration system built using **Core PHP, MySQL, HTML, and CSS**.

This project was created to practice the fundamentals of PHP form handling, user input validation, password hashing, MySQL database operations, and error handling without using a PHP framework.

## 🚀 Features

- User registration form
- Username and password input
- Server-side form validation
- Empty-field validation
- Password hashing using `password_hash()`
- MySQL database integration
- Duplicate username handling
- Exception handling using `try...catch`
- Basic responsive frontend styling
- PHP form submission using `POST`

## 🛠️ Technologies Used

- **PHP** – Backend logic
- **MySQL** – Database
- **HTML5** – Page structure
- **CSS3** – Styling
- **MySQLi** – PHP/MySQL database connection
